# Lada Blank — Website Prototype

A responsive one-page artist website prototype built around the visual language of **Monochrome Emotional Cinema** and the project **THERAPY**.

## Open locally
Open `index.html` in a modern browser.

## Files
- `index.html` — page structure and content
- `styles.css` — responsive layout and visual system
- `script.js` — navigation, modal, scroll reveals
- `assets/therapy-cover.jpg` — supplied album cover
- `assets/lada-portrait.png` — supplied artist portrait

## Before publishing
Replace the placeholder email and social links in the Contact section with the final addresses.
